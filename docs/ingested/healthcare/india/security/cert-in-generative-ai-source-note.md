# CERT-In Advisory CIAD-2025-0013 — source note

The Indian Computer Emergency Response Team advisory, **Best Practices against vulnerabilities while using Generative AI solutions**, describes risks including data poisoning, adversarial attacks, model inversion, model stealing, prompt injection, hallucination exploitation, and backdoors. It recommends avoiding personal or sensitive information in unapproved AI services, configuring access rights carefully, verifying outputs against reliable sources, not relying on AI alone for crucial decisions including medical contexts, and using secure access controls.

Use this source to derive requirements for synthetic-data-only operation, prompt-injection resistance, retrieval-source allowlisting, minimum permissions, output verification, human review, auditability, and clear intended-use boundaries.
